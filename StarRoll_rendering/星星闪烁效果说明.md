# ✨ 星星闪烁效果实现说明

## 功能概述

根据星星亮度（magnitude）添加差异化的闪烁效果，让星空更加生动真实。

## 实现原理

### 闪烁算法

```typescript
// 每个星星的闪烁计算
闪烁频率 = 1.0 + magnitude × 0.3
闪烁幅度 = 0.15 + (6.0 - magnitude) × 0.05

亮度变化 = sin(时间 × 频率 + 相位) × 幅度
最终亮度 = 1.0 + 亮度变化

范围：0.85 - 1.15（±15%波动）
```

### 分级闪烁效果

| 星等 | 闪烁频率 | 闪烁幅度 | 效果 |
|------|----------|----------|------|
| < 1.0 | 快（1.3倍） | 大（±20%） | 明显闪烁 ✨ |
| 1.0-2.5 | 中等（1.5倍） | 中（±15%） | 适度闪烁 ⭐ |
| 2.5-4.5 | 慢（2.0倍） | 小（±10%） | 轻微闪烁 • |

## 核心代码

### Vertex Shader（顶点着色器）

```glsl
attribute float magnitude;      // 星等
attribute float twinklePhase;  // 随机相位

uniform float uTime;           // 时间

varying float vTwinkle;        // 传递闪烁值

void main() {
    // 计算闪烁参数
    float twinkleSpeed = 1.0 + magnitude * 0.3;
    float twinkleAmount = 0.15 + (6.0 - magnitude) * 0.05;
    
    // 计算闪烁值
    float twinkle = sin(uTime * twinkleSpeed + twinklePhase);
    vTwinkle = 1.0 + twinkle * twinkleAmount;
    
    // 大小也会随闪烁变化
    gl_PointSize = uSize * vTwinkle;
}
```

### Fragment Shader（片段着色器）

```glsl
uniform sampler2D uTexture;
varying vec3 vColor;
varying float vTwinkle;

void main() {
    vec4 texColor = texture2D(uTexture, gl_PointCoord);
    
    // 应用闪烁：颜色和亮度都会变化
    vec3 finalColor = texColor.rgb * vColor * vTwinkle;
    
    gl_FragColor = vec4(finalColor, texColor.a);
}
```

## 闪烁参数详解

### 1. 闪烁频率（twinkleSpeed）

```typescript
twinkleSpeed = 1.0 + magnitude * 0.3

示例：
magnitude = 0.0  → speed = 1.0 (基础频率)
magnitude = 2.0  → speed = 1.6 (慢60%)
magnitude = 4.0  → speed = 2.2 (慢120%)

效果：亮星闪得快，暗星闪得慢
```

### 2. 闪烁幅度（twinkleAmount）

```typescript
twinkleAmount = 0.15 + (6.0 - magnitude) * 0.05

示例：
magnitude = 0.0  → amount = 0.45 (±45%波动)
magnitude = 2.0  → amount = 0.35 (±35%波动)
magnitude = 4.0  → amount = 0.25 (±25%波动)

效果：亮星闪烁明显，暗星闪烁轻微
```

### 3. 随机相位（twinklePhase）

```typescript
twinklePhase = Math.random() * Math.PI * 2  // 0-2π

作用：
- 每个星星有不同的起始相位
- 避免所有星星同步闪烁
- 创造自然的随机感
```

## 性能优化

### 1. 限制闪烁的星星数量

```typescript

    // 暗星不闪烁
    twinklePhases.push(0);
    // 在shader中检测到0就不闪烁
```

### 2. 降低更新频率

```typescript
// 不是每帧都更新
private lastTwinkleUpdate = 0;

animate() {
    const time = Date.now() * 0.001;
    
    // 每100ms更新一次（而不是每帧16ms）
    if (time - this.lastTwinkleUpdate > 0.1) {
        this.updateTwinkle(time);
        this.lastTwinkleUpdate = time;
    }
}
```

### 3. LOD（距离优化）
