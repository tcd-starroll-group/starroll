## 拍照识别算法准备

### 可识别的信息

#### 1. 星星位置
```javascript
每个星星的屏幕坐标 (x, y)
    ↓
对应的天球坐标 (RA, Dec)
    ↓
对应的HIP编号
    ↓
星星信息（名称、星等、颜色）
```

#### 2. 星星属性
```javascript
// 从渲染参数获取
magnitude: 视星等（亮度）
bvColor: B-V色指数（颜色）
size: 屏幕大小（像素）
position: 3D位置（世界坐标）
```

#### 3. 相机参数
```javascript
// 用于逆向计算
FOV: 75°
aspect: width/height
orientation: {
    azimuth: 方位角
    altitude: 仰角
}
```

### 识别算法流程

```
1. 拍照
   ↓
2. 图像预处理
   - 提取亮点（星星）
   - 计算亮点位置
   ↓
3. 匹配星表
   - 根据相机参数
   - 计算预期星星位置
   - 匹配实际星星
   ↓
4. 识别结果
   - 确定星星身份
   - 显示星星信息
   - 标注星座
```

### 关键数据导出

```typescript
// 获取当前可见的星星列表
const visibleStars = renderer.getVisibleStars();

// 每个星星包含：
{
    hip: number,           // HIP编号
    screenX: number,       // 屏幕X坐标
    screenY: number,       // 屏幕Y坐标
    magnitude: number,     // 视星等
    color: {r, g, b},     // 颜色
    worldPos: Vector3,    // 3D位置
    ra: number,           // 赤经
    dec: number          // 赤纬
}
```

## 故障排除

### Q: 星星还是太多？
A: 调整magnitude阈值
```typescript
// 更少的星星
if (star.magnitude > 3.5) return;  // 只显示非常亮的星
```

### Q: 星座轮廓不明显？
A: 增加透明度和边缘光
```typescript
uOpacity: 0.8,  // 从0.6增加到0.8
uRimPower: 1.6  // 从1.8减小到1.6（更宽的边缘）
```

### Q: 需要显示星星名称？
A: 只在点击时显示
```typescript

    showStarName(star);  // 临时显示
}
```
