## 📱 iOS 权限请求详解

### 为什么需要用户点击？

**Apple 安全策略：**
```
DeviceOrientationEvent.requestPermission()
    ↓
必须由用户手势触发（如按钮点击）
    ↓
不能自动调用
    ↓
否则会被浏览器拒绝
```

**代码实现（已完成）：**
```typescript
// ✅ 正确：由按钮点击触发
button.onclick = async () => {
    await enableARMode();  // 内部调用 requestPermission
};

// ❌ 错误：页面加载时自动调用
window.onload = async () => {
    await requestPermission();  // 会失败！
};
```

### 权限对话框

**iOS 系统对话框内容：**
```
"localhost" 想要访问
动作与方向

这将允许网站访问您的设备传感器数据

[不允许]      [允许]
```

**用户必须点击 "允许"**

### 权限状态

**三种状态：**
1. **prompt**（待请求）
   - 未请求过权限
   - 显示 "启用 AR 模式" 按钮

2. **granted**（已授予）
   - 用户点击了 "允许"
   - AR 模式可以启用
   - 按钮显示 "AR 模式已启用"

3. **denied**（已拒绝）
   - 用户点击了 "不允许"
   - 无法启用 AR
   - 需要清除网站数据重试

## 🐛 常见问题解决

### 问题 1：看不到 AR 按钮

**检查：**
- [ ] 服务器已启动
- [ ] 页面已加载完成
- [ ] 右下角应该有面板

**位置：**
- 右下角，距离底部 80px
- 蓝色半透明面板
- 如果是移动设备首次访问，还会有中心提示

### 问题 2：点击按钮没反应

**检查控制台：**
```javascript
// 应该看到
📱 正在请求传感器权限...

// 如果看到错误
❌ xxx
```

**可能原因：**
1. 不是 Safari 浏览器
2. 按钮事件未绑定
3. JavaScript 错误

**解决：**
- 使用 Safari
- F12 查看控制台错误
- 刷新页面重试

### 问题 3：权限对话框不弹出

**可能原因：**
1. 不是 HTTPS 或 localhost
2. iOS 版本太旧（< iOS 13）
3. Safari 设置禁用了传感器

**解决：**
1. 确认使用局域网地址（如 `http://10.x.x.x`）
2. 更新 iOS 到最新版本
3. Safari 设置 → 隐私 → 动作与方向访问 → 允许

### 问题 4：点击 "允许" 后还是失败

**检查：**
- 查看控制台错误信息
- 尝试重新加载页面
- 检查传感器是否真的工作

**调试：**
1. 打开 "传感器调试面板"
2. 查看权限状态
3. 查看传感器数据是否更新

### 问题 5：数据不更新

**可能原因：**
- 监听未启动
- 传感器损坏
- 浏览器bug

**解决：**
1. 打开调试面板
2. 点击 "开始测试"
3. 转动手机观察原始数据
4. 如果原始数据也不变，可能是硬件问题

## 💡 关键提示

### iOS 权限请求要点

**✅ 正确做法：**
```typescript
// 1. 用户点击按钮
button.onclick = async () => {
    // 2. 在点击事件处理函数中请求权限
    const permission = await DeviceOrientationEvent.requestPermission();
    
    // 3. 权限对话框会弹出
    if (permission === 'granted') {
        // 4. 用户授予权限
        startListening();
    }
};
```

**❌ 错误做法：**
```typescript
// ❌ 自动调用（会失败）
window.onload = async () => {
    await DeviceOrientationEvent.requestPermission();  // 失败！
};

// ❌ setTimeout 调用（会失败）
setTimeout(async () => {
    await DeviceOrientationEvent.requestPermission();  // 失败！
}, 1000);

// ❌ 非用户手势触发（会失败）
fetch('/api').then(async () => {
    await DeviceOrientationEvent.requestPermission();  // 失败！
});
```

### 按钮必须可见且可点击

**确保：**
- ✅ 按钮在视口内（不被遮挡）
- ✅ 按钮有足够大的点击区域
- ✅ z-index 足够高
- ✅ pointer-events 不是 none
