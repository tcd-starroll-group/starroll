# 🔧 去除PNG纹理黑边问题

## 问题描述

星星显示为黑色方块，PNG纹理的黑色背景没有被正确透明处理。

```
❌ 显示效果:
■ ■ ■  ← 黑色方块，有明显边框
■ ■ ■

✅ 预期效果:
⭐ ⭐ ⭐  ← 纯星点，无黑边
⭐ ⭐ ⭐
```

## 根本原因

### PNG纹理的透明度处理

PNG文件可能存在的问题：
1. 背景是黑色而不是透明（alpha=255）
2. 边缘有半透明的黑色像素（alpha=50-200）
3. 抗锯齿导致的灰色边缘

### WebGL的透明渲染

```javascript
// 即使设置了 transparent: true
// WebGL仍会渲染所有像素，包括黑色背景

默认行为:
黑色像素 (0,0,0, alpha=100) → 显示为半透明黑色 ❌
白色像素 (255,255,255, alpha=255) → 显示为白色 ✅
```

## 解决方案

### 方案1: alphaTest（推荐）✅

```typescript
// 已实现：添加 alphaTest 参数
new THREE.PointsMaterial({
    map: texture,
    transparent: true,
    alphaTest: 0.5,  // 关键！丢弃alpha<0.5的像素
    ...
});
```

**工作原理**：
```
像素的alpha值 < 0.5 → 完全丢弃（不渲染）
像素的alpha值 ≥ 0.5 → 正常渲染

结果：
黑色背景 (alpha=0 或很小) → 不渲染 ✅
星点中心 (alpha=1.0) → 渲染 ✅
边缘 (alpha=0.3) → 不渲染 ✅
```

### 方案2: 自定义Shader

```typescript
// 使用shader精确控制透明度
const material = new THREE.ShaderMaterial({
    uniforms: {
        uTexture: { value: texture }
    },
    vertexShader: `
        varying vec3 vColor;
        attribute vec3 color;
        
        void main() {
            vColor = color;
            vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
            gl_Position = projectionMatrix * mvPosition;
            gl_PointSize = 5.0;
        }
    `,
    fragmentShader: `
        uniform sampler2D uTexture;
        varying vec3 vColor;
        
        void main() {
            // 采样纹理
            vec4 texColor = texture2D(uTexture, gl_PointCoord);
            
            // 使用纹理的alpha通道
            // 如果alpha很小（黑色背景），直接丢弃
            if (texColor.a < 0.1) discard;
            
            // 应用星星颜色
            vec3 finalColor = texColor.rgb * vColor;
            
            gl_FragColor = vec4(finalColor, texColor.a);
        }
    `,
    transparent: true,
    blending: THREE.AdditiveBlending,
    depthWrite: false
});
```

## alphaTest参数详解

### 值的选择

```typescript
alphaTest: 0.1   // 很宽松，保留更多半透明像素
alphaTest: 0.5   // 推荐，平衡清晰度和柔和度
alphaTest: 0.8   // 严格，只保留高透明度像素
alphaTest: 0.01  // 几乎不丢弃，可能仍有黑边
```

### 不同值的效果

```
alphaTest = 0.1:
  ⭐  ← 较大，边缘柔和，可能有轻微黑边
  
alphaTest = 0.5:
  ⭐  ← 适中，边缘清晰，无黑边 ✅
  
alphaTest = 0.8:
  •   ← 较小，边缘锐利，可能丢失光晕
```

### 调整建议

根据效果调整alphaTest值：

```typescript
// 如果还有黑边
alphaTest: 0.6,  // 提高阈值

// 如果星星太小或消失
alphaTest: 0.3,  // 降低阈值

// 如果边缘太锐利
alphaTest: 0.4,  // 稍微降低
```

## 完整的修复代码

### 当前实现（已应用）

```typescript
private createStarPoints(
    starsData: Array,
    texturePath: string,
    baseSize: number
): THREE.Points {
    // ... 创建geometry
    
    const textureLoader = new THREE.TextureLoader();
    const texture = textureLoader.load(texturePath);
    
    // 优化纹理设置
    texture.minFilter = THREE.LinearFilter;
    texture.magFilter = THREE.LinearFilter;
    
    const material = new THREE.PointsMaterial({
        size: baseSize,
        map: texture,
        transparent: true,
        alphaTest: 0.5,  // 🔑 关键：去除黑边
        opacity: 1.0,
        vertexColors: true,
        sizeAttenuation: false,
        blending: THREE.AdditiveBlending,
        depthWrite: false
    });
    
    return new THREE.Points(geometry, material);
}
```

## 替代方案

### 如果alphaTest不够

#### 选项1: 使用程序化渲染（Shader）

```typescript
// 不使用PNG纹理，用shader画圆
fragmentShader: `
    varying vec3 vColor;
    
    void main() {
        // 计算距离中心的距离
        vec2 center = gl_PointCoord - vec2(0.5);
        float dist = length(center) * 2.0;
        
        // 圆形遮罩
        if (dist > 1.0) discard;  // 完全去除方形边缘
        
        // 径向渐变
        float alpha = 1.0 - smoothstep(0.0, 1.0, dist);
        
        gl_FragColor = vec4(vColor, alpha);
    }
`
```

#### 选项2: 使用Canvas动态生成纹理

```typescript
// 动态创建完美的星星纹理
function createStarTexture(size = 64): THREE.CanvasTexture {
    const canvas = document.createElement('canvas');
    canvas.width = size;
    canvas.height = size;
    const ctx = canvas.getContext('2d')!;
    
    const center = size / 2;
    const radius = size / 2;
    
    // 创建径向渐变
    const gradient = ctx.createRadialGradient(
        center, center, 0,
        center, center, radius
    );
    
    gradient.addColorStop(0, 'rgba(255, 255, 255, 1.0)');    // 中心亮
    gradient.addColorStop(0.3, 'rgba(255, 255, 255, 0.8)');  // 内圈
    gradient.addColorStop(0.6, 'rgba(255, 255, 255, 0.3)');  // 外圈
    gradient.addColorStop(1.0, 'rgba(255, 255, 255, 0.0)');  // 边缘透明
    
    ctx.fillStyle = gradient;
    ctx.fillRect(0, 0, size, size);
    
    return new THREE.CanvasTexture(canvas);
}

// 使用
const starTexture = createStarTexture(64);
material.map = starTexture;
```
