# 🔧 问题修复说明

## 修复的问题

### ✅ 1. AR方向反转问题

**问题描述**：
- 仰角显示为负值（-73.8°），相机在向下看地面而不是向上看天空
- 转动手机时方向不对，星空显示位置错误

**原因分析**：
- 传感器数据转换公式错误
- 原公式：`altitude = 90 - beta`
  - 当 beta=0（竖直握持）时，altitude=90°（天顶），应该是0°（平视）
  - 当 beta=90（平躺）时，altitude=0°（地平线），应该是90°（天顶）

**修复方案**：
- 修改公式为：`altitude = -beta`
- 现在的行为：
  - beta=0（竖直握持）→ altitude=0°（平视前方）✅
  - beta<0（向上仰）→ altitude>0°（仰视天空）✅
  - beta>0（向下俯）→ altitude<0°（俯视地面）✅

**修改文件**：
- `src/core/Tensors/sensor.ts` (第180行、第185行)

### ✅ 2. 星星过大过亮问题

**问题描述**：
- 星星渲染成巨大的光斑，完全遮挡了星空
- 亮度过高，无法看清星空结构

**原因分析**：
- 基础大小系数过大（120.0）
- 曝光值过高（4.0）
- 亮度增强倍数过高（最高3倍）

**修复方案**：
- 减小基础大小：120.0 → 30.0（减小到1/4）
- 降低曝光：4.0 → 1.5（减少62.5%）
- 减少亮度增强：
  - 一等星：3.0倍 → 1.8倍
  - 二等星：2.5倍 → 1.5倍
  - 三等星：2.0倍 → 1.3倍
  - 其他：1.5倍 → 1.1倍
- 移除HDR额外增亮（1.5倍）

**修改文件**：
- `src/core/renderer/GroundObserverRenderer.ts` (第306-308行、第334-338行、第366-382行)

   - 转动手机环顾四周（方位角变化）
   - 点击星星查看详细信息

## 故障排除

### 如果方向仍然不对

1. **检查传感器校准**：
   - 在空旷的地方转动手机画"8"字
   - 重启手机后重新打开应用

2. **检查浏览器兼容性**：
   - iOS：必须使用 Safari
   - Android：推荐使用 Chrome 或 Firefox

3. **检查 HTTPS**：
   - iOS 需要 HTTPS 才能使用传感器
   - 确认地址栏显示安全锁图标

### 如果星星还是太亮

可以进一步调整这些参数（在代码中）：
- `uExposure`：曝光值（当前1.5，可以降到1.0-1.2）
- `uBaseSize`：基础大小（当前30.0，可以降到20.0-25.0）

### 如果位置获取失败

1. **检查浏览器权限**：
   - 设置 → Safari → 位置 → 允许
   - 设置 → 应用 → Chrome → 位置 → 允许

2. **手动点击按钮**：
   - 左上角"📍 使用当前位置"
   - 在弹出的权限对话框中点击"允许"

3. **检查GPS是否开启**：
   - 设置 → 隐私 → 定位服务 → 开启

## 技术细节

### 传感器数据转换

```typescript
// iOS/Android 设备方向事件数据
alpha: 0-360°   // 指南针方向（方位角）
beta: -180-180° // 前后倾斜
gamma: -90-90°  // 左右倾斜

// 转换为天文坐标
azimuth = alpha           // 方位角保持不变
altitude = -beta          // 仰角 = 负的倾斜角
```

### 星等到亮度转换

```typescript
// 星等转亮度（标准天文公式）
intensity = pow(10.0, -0.4 * magnitude)

// 视星等越小，星星越亮
magnitude = 0.0  → intensity = 1.0    (天狼星级别)
magnitude = 3.0  → intensity = 0.251  (普通亮星)
magnitude = 6.0  → intensity = 0.063  (肉眼极限)
```
