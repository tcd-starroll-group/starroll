## 🐛 常见问题

### Q: iOS 点击 AR 按钮没反应？

**原因：** iOS 需要用户手势触发权限请求

**解决：**
1. 确保点击的是按钮（不是其他区域）
2. 查看是否弹出权限对话框
3. 如果没有弹出，查看控制台错误

### Q: 权限请求被拒绝怎么办？

**解决方法：**
1. iOS 设置 → Safari → 高级 → 网站数据
2. 清除该网站数据
3. 重新打开网页
4. 再次点击 AR 按钮

### Q: 传感器数据不更新？

**检查：**
1. 打开调试面板
2. 查看传感器原始数据是否变化
3. 确认 "开始测试" 已点击
4. 确认权限状态为 "已授予"

### Q: 星空方向不对？

**可能原因：**
- 磁力计未校准
- alpha 值不准确

**解决：**
1. 校准手机指南针（设置中）
2. 远离磁场干扰
3. 或使用相对方向（不依赖绝对北方）

### Q: Android 方向相反？

**原因：** Android 和 iOS 坐标系可能不同

**解决：**
编辑 `sensor.ts` 第 182 行，调整 Android 计算方式

## 🔍 调试技巧

### 1. 查看原始传感器数据

打开调试面板，观察三个数值：

**Alpha（方位角）：**
- 手机水平，顶部指北 → 0°
- 顶部指东 → 90°
- 顶部指南 → 180°
- 顶部指西 → 270°

**Beta（俯仰角）：**
- 手机竖直 → 0°
- 屏幕朝上平躺 → 90°
- 屏幕朝下平躺 → -90°

**Gamma（翻滚角）：**
- 手机不倾斜 → 0°
- 向右倾斜 → 正值
- 向左倾斜 → 负值

### 2. 验证相机朝向计算

**公式：**
```typescript
方位角 = Alpha
仰角 = 90° - Beta
```

**测试：**
- 手机水平朝北 → 方位角 0°，仰角 0°
- 手机竖直向上 → 仰角 90°
- 手机倾斜45° → 仰角 45°

### 3. 对比参考星座

**已知星座位置（上海，当前时间）：**
- 北极星：方位角 0°，仰角约 31°（等于纬度）
- 天顶星座：仰角 90°
- 东方星座：方位角 90°

**验证方法：**
1. 找到北极星方向
2. 指向北极星
3. 查看方位角应接近 0°
4. 仰角应接近 31°

## 🔧 故障排查

### 问题 1：权限请求不弹出

**原因：**
- iOS 要求 HTTPS 或 localhost
- 必须由按钮点击触发

**解决：**
- 确认使用 Safari（不是 Chrome）
- 确认由按钮点击触发

### 问题 2：传感器数据都是 null

**原因：**
- 权限未授予
- 设备不支持
- 浏览器不支持

**解决：**
- 检查权限状态
- 使用 Safari（iOS）
- 检查设备型号

### 问题 3：方向不准确

**原因：**
- 磁力计未校准
- 周围有磁场干扰
- absolute: false

**解决：**
- 校准指南针（系统设置）
- 远离电子设备
- 户外测试效果更好

### 问题 4：星空旋转方向相反

**原因：**
- 坐标系映射不对

**解决：**
- 调整 `updateCameraFromSensor` 中的符号
- 根据实际测试调整
