## 代码实现

### 当前实现（PNG纹理）

```typescript
private createStarMaterial(): THREE.PointsMaterial {
    // 加载PNG纹理
    const textureLoader = new THREE.TextureLoader();
    const starTexture = textureLoader.load('/texture/Light.png');
    
    return new THREE.PointsMaterial({
        size: 3.0,              // 基础大小（像素）
        map: starTexture,       // PNG纹理贴图
        transparent: true,       // 透明
        opacity: 1.0,           // 不透明度
        vertexColors: true,     // 使用顶点颜色（星星颜色）
        sizeAttenuation: true,  // 距离衰减
        blending: THREE.AdditiveBlending,  // 叠加混合
        depthWrite: false       // 不写入深度
    });
}
```

```typescript
private createStarMaterial(mode: 'light' | 'round' = 'light'): THREE.PointsMaterial {
    const textureLoader = new THREE.TextureLoader();
    const texturePath = mode === 'light' 
        ? '/texture/star16x16_ray.png'   // 发光效果
        : '/texture/star16x16.png';  // 简单圆点
    
    const starTexture = textureLoader.load(texturePath);
    
    return new THREE.PointsMaterial({
        size: mode === 'light' ? 3.0 : 2.0,  // 根据纹理调整大小
        map: starTexture,
        transparent: true,
        opacity: mode === 'light' ? 1.0 : 0.9,
        vertexColors: true,
        sizeAttenuation: true,
        blending: THREE.AdditiveBlending,
        depthWrite: false
    });
}
```

### 基于星等的大小

```typescript
// 需要在shader中计算，或者使用自定义属性
private createStarMaterial(): THREE.PointsMaterial {
    const material = new THREE.PointsMaterial({
        size: 3.0,
        map: starTexture,
        transparent: true,
        vertexColors: true,
        sizeAttenuation: true
    });
    
    // 自定义大小（需要shader）
    material.onBeforeCompile = (shader) => {
        shader.vertexShader = shader.vertexShader.replace(
            'gl_PointSize = size;',
            `
            // 根据星等调整大小
            attribute float aMagnitude;
            float intensity = pow(10.0, -0.4 * aMagnitude);
            gl_PointSize = size * intensity * 2.0;
            `
        );
    };
    
    return material;
}
```

## 创建更好的星星纹理

### PNG纹理设计建议

#### 推荐尺寸
- **64x64** - 平衡质量和性能
- **128x128** - 高质量
- **256x256** - 超高质量（可能过大）

#### 设计要素

1. **透明背景**
   ```
   背景: 完全透明 (alpha = 0)
   ```

2. **中心亮点**
   ```
   中心: 纯白色，高亮 (255, 255, 255, 255)
   ```

3. **渐变光晕**
   ```
   核心 (0-30%): alpha = 1.0
   内晕 (30-60%): alpha = 0.8-0.5
   外晕 (60-100%): alpha = 0.5-0.0
   ```

4. **径向渐变**
   ```
   使用径向渐变工具
   从中心到边缘逐渐透明
   ```

### Photoshop制作步骤

```
1. 新建文件: 64x64, 透明背景
2. 选择渐变工具: 径向渐变
3. 设置颜色: 白色(255,255,255) → 透明
4. 从中心向外拉渐变
5. 调整: 滤镜 → 模糊 → 高斯模糊 (2-3px)
6. 调整: 图层 → 发光效果
7. 导出: PNG-24, 保留透明度
8. 保存到: public/texture/star.png
```

## 优化建议

### 1. 根据星等调整大小

```typescript
// 在创建星点时
const sizes: number[] = [];

stars.forEach(star => {
    // 根据星等计算大小
    const intensity = Math.pow(10, -0.4 * star.magnitude);
    const size = 2.0 + intensity * 8.0;  // 2-10像素
    sizes.push(size);
});

// 添加size属性
geometry.setAttribute('size', new THREE.Float32BufferAttribute(sizes, 1));

// 材质中启用自定义大小
material.onBeforeCompile = (shader) => {
    shader.vertexShader = shader.vertexShader.replace(
        'uniform float size;',
        'uniform float size;\nattribute float size;'
    ).replace(
        'gl_PointSize = size;',
        'gl_PointSize = size;'  // 使用顶点size
    );
};
```

### 2. 预加载纹理

```typescript
// 在构造函数中预加载
constructor(container: HTMLElement) {

private async preloadTextures(): Promise<void> {
    const textureLoader = new THREE.TextureLoader();
    
    const textures = await Promise.all([
        textureLoader.loadAsync('/texture/Light.png'),
        textureLoader.loadAsync('/texture/round.png')

    this.starTextures = textures;
}
```

## 常见问题

### Q: 星星看不见或很暗？

A: 调整大小和不透明度
```typescript
size: 5.0,      // 增大
opacity: 1.5,   // 增加（如果支持HDR）
```

### Q: 星星太亮或太大？

A: 减小参数
```typescript
size: 2.0,      // 减小
opacity: 0.8,   // 降低
```

### Q: 纹理加载失败？

A: 检查路径
```typescript
// 确保路径正确
console.log('纹理路径:', '/texture/star16x16_ray.png');

// 监听加载错误
textureLoader.load(
    '/texture/Light.png',
    (texture) => console.log('✅ 纹理加载成功'),
    undefined,
    (error) => console.error('❌ 纹理加载失败:', error)
);
```

### Q: 想同时使用多个纹理？

A: 创建多个Points对象
```typescript
// 亮星用一种纹理
const brightStars = new THREE.Points(
    brightGeometry,
    new THREE.PointsMaterial({ map: lightTexture })
);

// 暗星用另一种纹理
const dimStars = new THREE.Points(
    dimGeometry,
    new THREE.PointsMaterial({ map: roundTexture })
);
```

## 星轨渲染准备

### PNG纹理对星轨的优势

使用PNG纹理对后续星轨渲染有好处：

✅ **清晰的轨迹点**
- 每个轨迹点都是清晰的PNG星点
- 连成线后效果自然

✅ **性能优势**
- 简单的材质，渲染快
- 适合大量轨迹点

✅ **一致的外观**
- 静止的星星和轨迹上的星星看起来一样
- 视觉统一

### 星轨实现预览

```typescript
class StarTrailRenderer {
    // 轨迹也使用同样的PNG纹理
    createTrailPoints(positions: Vector3[]) {
        const geometry = new THREE.BufferGeometry();
        geometry.setFromPoints(positions);
        
        // 使用相同的星星纹理
        const material = new THREE.PointsMaterial({
            size: 2.0,  // 轨迹点稍小
            map: this.starTexture,  // 相同的纹理
            transparent: true,
            opacity: 0.6,  // 轨迹点稍暗
            vertexColors: true,
            blending: THREE.AdditiveBlending
        });
        
        return new THREE.Points(geometry, material);
    }
}
```
